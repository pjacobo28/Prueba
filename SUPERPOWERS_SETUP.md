# Superpowers MCP Server Installation

## ¿Qué es Superpowers?

Superpowers es un framework integral de habilidades que enseña a Claude metodologías estructuradas de desarrollo de software profesional. Proporciona habilidades componibles para TDD, depuración sistemática, lluvia de ideas, desarrollo impulsado por subagentes con revisión de código integrada, y la capacidad de crear nuevas habilidades.

## Características principales

### 1. **Test-Driven Development (TDD)**
- Ciclos "red-green-refactor" donde las pruebas DEBEN fallar antes de la implementación
- Asegura código testeable y de calidad desde el inicio

### 2. **Depuración Sistemática**
- Metodología de cuatro fases que requiere investigación de causa raíz antes de cualquier solución
- Análisis de patrones, pruebas de hipótesis e implementación disciplinada
- Salvaguardas que disparan revisión arquitectónica después de 3 intentos fallidos

### 3. **Sesiones de Lluvia de Ideas (Brainstorming)**
- Enfoque socrático que refina requisitos antes de codificar
- Explora diseño y alternativas arquitectónicas

### 4. **Desarrollo Impulsado por Subagentes**
- Revisión de código integrada
- Los agentes evalúan implementaciones contra planes, estándares de codificación y principios arquitectónicos

### 5. **Autoría de Nuevas Habilidades**
- Módulo de escritura de habilidades
- Enseña TDD aplicado a documentación

## Cómo usar Superpowers

Invoca habilidades con comandos slash:

### Ejemplos principales:

```bash
/brainstorming
# Explora requisitos y diseño antes de implementación
# Sesiones socrática que refinan especificaciones
```

```bash
/execute-plan
# Ejecuta planes de implementación por lotes
# Con puntos de control de revisión
```

### Flujo de trabajo típico:

1. **Inicio:** `/brainstorming` - Refina requisitos y diseño
2. **Planificación:** Define la arquitectura y enfoque
3. **Ejecución:** `/execute-plan` - Implementa con revisiones integradas
4. **Depuración:** Si es necesario, usa metodología sistemática de cuatro fases
5. **Revisión:** Agente revisor evalúa contra estándares

## Prácticas disciplinadas

### Red-Green-Refactor TDD
- **Red:** Escribe test que falla
- **Green:** Implementa código mínimo para pasar
- **Refactor:** Mejora sin cambiar comportamiento

### Depuración de 4 fases
1. Investigación de causa raíz
2. Análisis de patrones
3. Prueba de hipótesis
4. Implementación de solución

### Revisión arquitectónica automática
- Se dispara después de 3 intentos fallidos
- Evalúa enfoque fundamental

## Notas para trabajo legal

Superpowers es especialmente valioso para proyectos legales porque:
- **TDD garantiza cobertura de casos críticos** - Esencial para cumplimiento normativo
- **Depuración sistemática** - Traza documentada de investigación
- **Revisión arquitectónica** - Asegura patrones seguros y conformes
- **Documentación disciplinada** - Meets requirements de auditoría
