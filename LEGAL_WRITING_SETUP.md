# Legal Writing Assistant MCP Server Installation

## ¿Qué es Legal Writing?

Legal Writing Assistant es un servidor MCP que proporciona plantillas de documentos legales, valida estructura de demandas, mejora redacción jurídica y asegura cumplimiento de requisitos formales.

## Características principales

### 1. **Plantillas de Documentos**
- Demandas y contrademandas
- Demandas con distintos tipos de acción
- Escritos de amparo y tutela
- Recursos de apelación y revisión
- Convenios y acuerdos

### 2. **Validación de Estructura**
- Verifica elementos obligatorios
- Valida numeración y referencias
- Comprueba citas normativas
- Revisa formato y presentación

### 3. **Mejora de Redacción**
- Detecta lenguaje impreciso
- Sugiere terminología legal
- Mejora claridad de argumentos
- Fortalece conclusiones

### 4. **Análisis de Argumentación**
- Estructura lógica de argumentos
- Identifica saltos lógicos
- Valida contra jurisprudencia
- Detecta debilidades en defensa

## Cómo usar Legal Writing

### Generar demanda:
```bash
/draft-complaint civil-matter
# Crea estructura de demanda civil
```

### Validar documento:
```bash
/validate-legal-document
# Verifica elementos obligatorios
```

### Mejorar redacción:
```bash
/improve-writing
# Sugiere mejoras de claridad y precisión
```

### Análisis de argumentación:
```bash
/analyze-argumentation
# Evalúa estructura de argumentos
```

### Generar recurso:
```bash
/draft-appeal appeal-type
# Crea escritos de apelación/revisión
```

## Flujo de trabajo para redacción

1. Selecciona tipo de demanda
2. Recopila información del caso
3. Ejecuta `/draft-complaint`
4. Completa secciones
5. Ejecuta `/validate-legal-document`
6. Mejora con `/improve-writing`
7. Revisa argumentación
8. Genera documento final
