### 4️⃣ **Document Analysis** - Analiza Documentos
```

```

## 🎯 Casos de Uso Rápidos

### Necesito redactar una demanda civil

```
Paso 1: /brainstorming
→ Reflexiona sobre argumentos

Paso 2: /draft-complaint civil
→ Genera estructura

Paso 3: /validate-legal-document
→ Verifica requisitos

Paso 4: /review-legal-compliance
→ Valida conformidad

Tiempo: 30-45 minutos (vs 2-3 horas manual)
```

### Necesito investigar jurisprudencia

```
Paso 1: /search-jurisprudence "derecho laboral"
→ Busca fallos

Paso 2: /analyze-precedents
→ Compara casos

Paso 3: /add-to-knowledge-base
→ Guarda para consultas futuras

Tiempo: 20-30 minutos (vs 3-4 horas manual)
```

### Necesito analizar un expediente

```
Paso 1: /process-pdf "expediente.pdf"
→ Extrae contenido

Paso 2: /analyze-case-file
→ Estructura información

Paso 3: /create-md-document
→ Documenta análisis

Tiempo: 15-20 minutos (vs 1-2 horas manual)
```

### Necesito monitorear mis casos

```
Paso 1: /create-automation-workflow "case-monitor"
→ Define qué monitorear

Paso 2: /automate-form "portal-judicial.com"
→ Configura navegación

Paso 3: Ejecuta automáticamente cada 4 horas
→ Sistema verifica por ti

Beneficio: Conoces cambios en minutos, no días
```

3. Inicia sesión con tu cuenta

### ¿Es seguro?
```
Sí, siempre que:
✅ No compartas credenciales
✅ Uses variables de entorno
✅ Encriptes datos sensibles
✅ Respetar términos de servicio
```

### ¿Cuánto cuesta?
```
Claude Code es gratuito. Algunos plugins 
pueden tener costos de infraestructura si 
los ejecutas en cloud 24/7.
```

### ¿Puedo usar offline?
```
La versión web requiere conexión.
La aplicación desktop puede funcionar
parcialmente offline.
```

### ¿Es legal automatizar portales judiciales?
```
Verifica con tu abogado y los términos
de servicio de cada portal. En general:
✅ Legal si respetas robots.txt
✅ Legal si no sobrecargas servidor
❌ Ilegal si violas términos de servicio
```
