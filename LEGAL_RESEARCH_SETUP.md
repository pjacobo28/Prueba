# Legal Research MCP Server Installation

## ¿Qué es Legal Research?

Legal Research es un servidor MCP que automatiza la investigación de jurisprudencia, permite búsquedas estructuradas de casos precedentes y organiza información legal por tema, jurisdicción y relevancia.

## Características principales

### 1. **Búsqueda de Jurisprudencia**
- Busca fallos y sentencias
- Filtra por jurisdicción
- Organiza por tema legal
- Identifica precedentes relevantes

### 2. **Análisis de Precedentes**
- Compara casos similares
- Identifica líneas jurisprudenciales
- Mapea evolución de criterios
- Encuentra contra-precedentes

### 3. **Investigación Temática**
- Busca por áreas de derecho
- Agrupa casos relacionados
- Genera síntesis temáticas
- Identifica vacíos normativos

### 4. **Análisis de Citación**
- Identifica fallos citados
- Mapea redes de referencias
- Encuentra casos influyentes
- Detecta cambios de criterio

## Cómo usar Legal Research

### Búsqueda de jurisprudencia:
```bash
/search-jurisprudence keyword jurisdiction
# Busca sentencias sobre tema en jurisdicción
```

### Análisis de precedentes:
```bash
/analyze-precedents
# Compara y analiza casos similares
```

### Investigación temática:
```bash
/research-topic legal-topic
# Investigación profunda por área
```

### Timeline jurisprudencial:
```bash
/jurisprudence-timeline
# Evolución de criterios en el tiempo
```

## Flujo de trabajo para investigación

1. Define tema y jurisdicción
2. Ejecuta `/search-jurisprudence`
3. Analiza resultados con `/analyze-precedents`
4. Identifica líneas jurisprudenciales
5. Usa en argumentación de demandas
